# Карманный инженер ИЖС

Бесплатный онлайн-калькулятор для частного дома: плитный и ленточный фундамент, кровля, стропила, деревянная балка перекрытия. Расчёт по СП с вердиктом «проходит / не проходит».

Сайт: https://azatgirya116.github.io/kalk-izhs/

Автор: инженер-конструктор Азат Камалиев («Камалстрой»). Расчёты ориентировочные и не заменяют проект.
